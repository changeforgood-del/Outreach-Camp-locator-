# Outreach Camp Nearby v2

Private, mobile-first field map for coordinated homeless outreach.

## Live app

https://outreach-camp-nearby.retroskillzgaming.chatgpt.site

The live app is private because it stores exact outreach locations. Authorized users can log a camp, use GPS to see nearby locations, receive proximity alerts while the app is open, open directions, and confirm:

- Still there
- No longer there
- Needs follow-up

## Privacy

Do not enter names, medical information, or identifying details about people at a location. The map is intended for coordinated outreach, not enforcement or public posting.

## Source

This folder contains the v2 product-specific interface, API, database schema, installable-app manifest, and service worker. The production project uses the OpenAI Sites Vinext starter with Cloudflare D1 for shared records.
